# God Mode Functionality

God mode is a shared shortcut feature that changes Box Empire's tutorial behavior.

## Activation

The player can toggle god mode from the top bar or by typing the god-mode shortcut.

## Starting Conditions

When the tutorial starts with god mode active:

- Both gatehouse lanes start open.
- Equipment starts enabled.

This lets the operation proceed with fewer manual tutorial steps.

## Cost Suppression

God mode prevents operating cost deductions for:

- Reach stacker move costs
- Quay crane import unload costs

Revenue can still be earned.

## Tutorial and Narrator Suppression

When god mode is active, narrator and tutorial dialogue prompts are hidden.

This allows the player to observe or fast-forward the operation without guided interruptions.

## Camera Suppression

God mode suppresses event-driven guided camera pans.

The player remains in control of the camera instead of being moved to tutorial focus areas.
