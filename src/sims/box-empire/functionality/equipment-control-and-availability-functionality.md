# Equipment Control and Availability Functionality

The player can inspect and control terminal equipment during the tutorial.

## Equipment List

The equipment list shows the available machines and their current work status.

The current tutorial includes:

- Reach stacker
- Mobile harbor crane

Selecting a machine opens its details.

## On and Off Control

Each machine can be turned on or off.

When a machine is off:

- It does not accept new work.
- It does not continue normal work assignment.

When a machine is on:

- It can accept suitable work if it is idle.
- It still respects its service restrictions or crane mode.

## Reach Stacker Service Controls

The reach stacker has separate controls for landside and waterside work.

Turning off landside service stops it from accepting truck-related jobs.

Turning off waterside service stops it from accepting quay-related jobs.

## Crane Mode Controls

The mobile harbor crane can be limited to discharge, load, or both.

This lets the player decide whether it should unload imports, load exports, or handle both directions.

## Current Job Display

When equipment has active work, the detail panel shows:

- The assigned job
- The job status
- The route type
- Whether the machine is carrying a container
