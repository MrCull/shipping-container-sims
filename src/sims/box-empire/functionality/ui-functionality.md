# UI Functionality

The Box Empire user interface helps the player control the terminal and understand the current operation.

## Start Screen

The start screen introduces Box Empire and starts the tutorial.

It explains that the player will manage truck arrivals, store containers, load and discharge vessels, and earn revenue.

## Top Bar

The top bar shows:

- Main menu button
- Money balance
- Simulation time
- Time speed controls
- God mode control
- Audio control

## Time Controls

The player can pause or change the simulation speed.

Current speed options are:

- Pause
- 1x
- 2x
- 3x
- 5x
- 10x
- 20x
- 50x
- 100x

## Event Feed

The event feed shows the most recent terminal events, including container moves, vessel changes, truck events, job updates, tutorial completion, and money changes.

## Job Queue

The job queue shows active, pending, assigned, in-progress, and blocked jobs. Completed and cancelled jobs are not shown.

The player can expand a job to see more detail about its container, status, equipment, pickup, and destination.

## Selected Container Panel

Selecting a container shows:

- Container identity
- Shipping line and color
- Import or export direction
- Status
- Size and weight
- Current location
- Dwell time
- Revenue earned
- Active job, if any

## Selected Equipment Panel

Selecting equipment shows:

- Equipment type
- On or off status
- Current work state
- Carried container, if any
- Current job, if any
- Reach stacker service controls or crane mode controls

## Selected Gatehouse Panel

Selecting a gatehouse area shows whether its lane is open or closed and lets the player toggle it.

## Completion and Career Screens

After the tutorial, the UI shows the tutorial results and offers replay or career continuation.
