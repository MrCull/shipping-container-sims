# Reference material (not committed)

Drop user-supplied reference packs here, for example the TTI Algeciras pack (dimensions, workflows, photos). Everything in this folder except this README is git-ignored.

Model tickets read it for real proportions. Without it, asset sidecars tag dimensions `A` (assumed). If a ticket needs it and the folder is empty, ask the user to upload it.
