# Container reference photos

Real 20 ft (22G1) containers, supplied by the project owner as the look to match when modelling and painting containers
(Terminal Twin hero faces and close-up markings). Not for redistribution outside this repository.

| File | Shows |
| --- | --- |
| `caxu-20ft-three-quarter-door-end.png` | Weathered red box, door end and side. Door leaves are corrugated in horizontal bands; two locking bars per leaf; identity top right, weight plate below it, hazard-style plate on the left leaf. |
| `jdlu-20ft-door-end-on-chassis.jpg` | Blue box, door end square on. Four locking bars with cam keepers and handles at the lower third, check digit boxed, "22G1" under the number, MAX GROSS / TARE / PAYLOAD / CU. CAP. block beside the right-hand outer bar, CSC plate and corten steel plate on the left leaf, SUPER HEAVY triangle. |
| `coyu-20ft-door-end-new-blue.png` | New blue box, door end square on. Three bars visible with the leaf seam, cleanly stencilled number, weight block right of the outer bar, Lloyd's certification plate left, handle bars in galvanised grey. |
| `jdlu-20ft-side-and-door-corner.jpg` | The same blue box from the side: vertical wall ribs, box number printed vertically near the door end, 22G1 and height plate, weathered paint with scuffs and rust at the corner. |

What the generators and the lettering layout take from them: `DOOR_BANDS`, `DOOR_BAR_FRACS` (`containers.py`,
`hero_containers.py`), `drawDoorMarks` (`containerTextures.ts`). Dimensions come from ISO 668, not from the photos.
