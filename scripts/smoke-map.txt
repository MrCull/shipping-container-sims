# Path pattern (extended regex on a changed file path) => smoke groups (space separated; `all` means every group).
# scripts/smoke-select.mjs prints the groups a change needs; CI and merge-ticket.sh run them. `core` always runs.
# A group is a Playwright tag on every test of a spec file (`{ tag: '@camera' }`); scripts/check-smoke-groups.mjs
# (part of verify) fails when a spec has no group tag or more than one. A changed *.smoke.ts selects its own group.
# Ignored before the map: paths outside src/, Markdown, docs/ folders, Node-only CLI code (src/sims/*/cli/) and
# unit tests (*.test.ts). Patterns match a file or folder name, never a substring of a path (the word "tests"
# contains "sts"). Add a line when a new area gets its own spec.
